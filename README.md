# Research Update (temporary workbench)

Coordination for the Better To Best research update, started October 2026:

1. develop the [Compassionism Simulation](https://bettertobest.github.io/compassionism-simulation/) and verify the early findings;
2. rebuild the [Research Hub](https://bettertobest.github.io/research-hub/) on the verified findings (Hub v2), keeping v1 as an archive;
3. finish the [Normative Economic Evaluation Criteria](https://bettertobest.github.io/NormativeEvaluation/) (NEEC) on those sources.

The work itself lands in those repositories. This one holds the plan (`PLAN.md`), the current state (`HANDOFF.md`), the rules every session follows (`CLAUDE.md`), study preregistrations (`prereg/`, committed before any run so anyone can check the analysis was fixed in advance) and audit triage (`audits/`).

Sessions run in Claude Code: `/start-session <step ID>` begins a step from the plan, `/end-session` records it and names the next one.
